# DimCalculator 用户手册

---

## 快速上手

**DimCalculator** 是一款为高中物理学习设计的智能量纲计算器。
本软件支持直接输入带单位的表达式（如 `5*m + 20*cm`），自动进行单位换算和量纲检查，并给出清晰的计算结果。

（本软件尚处于测试阶段，尚不稳定）

输入示例：
- `5m+20cm` = `5.2m`
- `10kg×9.8m/s²` = `98N`
- `100J÷10s` = `10W`
- `sin(30°)` = `0.5`

点击“=”或按回车键执行计算。

&nbsp;
## 单位

包含高中阶段常用物理单位：（部分不常用单位（非粗体）目前在界面中不显示）

**长度**：**m**, **km**, **cm**, **mm**, µm, **nm**, mile, ft（英尺）, ly（光年）

**面积**：**m²**, **cm²**, mm²

**体积**：**m³**, **cm³**, mm³, **L**, **mL**

**(角)速度/加速度**：**m/s**, **km/h**, **m/s²**, **rad/s**, **rad/s²**

**角度**：**rad**, **°**

**时间**：**s**, **ms**, **min**, **h**, d（天）

**频率/转速**：**Hz**, r（转）, **r/min**, r/s

**力学**：**kg**, **t**, **g**, mg, **u**, **g/cm³**, **kg/m³**, **N**, **Pa**, atm, **mmHg**

**能量与功率**：**J**, cal, **eV**, **kWh**, **W**, **kW**

**热学**：**K**, **°C**, °F, **Δ°C**, Δ°F, **J/(kg·K)**, **J/(kg·°C)**

**电磁学**：**A**, **mA**, **V**, **mV**, **Ω**, **C**, **Ah**, **mAh**, F, H, T, Wb

**化学**：**mol**, **mol/L**, **kg/mol**, **g/mol**

**光学**：cd

- **注：°C，°F是偏移单位，作温差时请使用Δ°C，Δ°F**

你也可以自由组合新的复合单位，如`N·m`。

&nbsp;
## 物理常数

在表达式中可以直接使用常见物理常数，和一些常见数学常数（如`π`, `e`（自然常数）等）。

- **注：为了与单位相区分，本软件中所有物理常数都以下划线开头（如_g），而数学常数不变（如π，e）**
- **注：程序使用高精度常数，如_g=9.80665m/s²。**

&nbsp;
## 函数

| 函数 | 说明 |
|------|------|
| sin(x) | 正弦（角度或弧度） |
| cos(x) | 余弦（角度或弧度） |
| tan(x) | 正切（角度或弧度） |
| sqrt(x) | 平方根 |
| abs(x) | 绝对值 |
| log(x, base) | 以 base 为底的对数 |
| lg(x) | 常用对数（以10为底） |
| ln(x) | 自然对数（以e为底） |

&nbsp;
## 特殊功能

- **ans**：引用上一次计算的结果。例如先算 `10m`，再输入 `ans×2` 得到 `20m`。
- **单位转换**：先点击“单位转换”按钮进入转换模式，再点击目标单位按钮，即可将当前结果转换到该单位。
- **错误提示（暂不成熟）**：当表达式有误时，下方信息区会显示具体原因和建议修改方式。
