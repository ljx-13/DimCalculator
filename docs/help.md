# DimCalculator 使用帮助

## 快速上手

DimCalculator 是一款支持物理单位运算的计算器。你可以直接在表达式中混合使用不同单位，程序会自动换算。

输入示例：
- `5m + 20cm` → `5.2m`
- `10kg × 9.8m/s²` → `98N`
- `100J ÷ 10s` → `10W`
- `sin(30°)` → `0.5`

点击“=”或按回车键执行计算。


## 运算符

| 符号  | 含义             |
|-----|----------------|
| +   | 加法             |
| -   | 减法             |
| ×   | 乘法             |
| ÷   | 除法             |
| ^   | 幂运算（如 2³ = 8） |
| ( ) | 括号             |


## 单位

支持所有常用物理单位：

**长度**：m, km, cm, mm, um, nm, mile, ft, ly

**面积**：m², cm², mm²

**体积**：m³, cm³, mm³, L, mL

**质量**：kg, g, mg, t, u

**时间**：s, ms, min, h, d

**温度**：K, °C（摄氏温度）, °F（华氏温度）

**电学**：A, mA, V, mV, Ω, C, F, H, Wb, T

**导出单位**：N, J, W, Pa, Hz

**角度**：rad, °（度）

**转速**：r（转）, r/min, r/s

你也可以自由使用复合单位，如 `m/s`、`kg/m³`、`J/(mol·K)`。

## 特殊功能

- **ans**：引用上一次计算的结果。例如先算 `10m`，再输入 `ans × 2` 得到 `20m`。

- **单位转换**：先点击“单位转换”按钮进入转换模式，再点击目标单位按钮，即可将当前结果转换到该单位。


## 错误提示（暂不成熟）

当表达式有误时，下方信息区会显示具体原因和建议修改方式。

常见错误：
- 单位不匹配（如长度加时间）
- 未定义的名称（拼写错误或使用了不存在的单位）
- 语法错误（括号不匹配、运算符连续）


## 注意事项

- **温度单位`°C`和`°F`是偏移单位，作温差计算时请使用`△°C`和`△°F`**
- **程序使用高精度常数。**
- **为了与单位相区分，本软件中所有物理常数都以下划线开头（如_g），而数学常数不变（如π，e）**
