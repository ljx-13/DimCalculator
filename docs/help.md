# DimCalculator 用户手册

---

## 快速上手

**DimCalculator** 是一款为高中物理学习设计的智能量纲计算器。
本软件支持直接输入带单位的表达式（如 `5*m + 20*cm`），自动进行单位换算和量纲检查，并给出清晰的计算结果。

（本软件尚处于测试阶段，尚不稳定）

输入示例：
- `5m+20cm` = `5.2m`
- `10kg×9.8m/s²` = `98N`
- `100J÷10s` = `10W`
- `sin(30°)` = `0.5`

点击“=”或按回车键执行计算。


## 单位

包含高中阶段常用物理单位：
- **注：带 `\*` 为不常用单位，默认不显示，但仍可正常使用，可在设置中启用。不常用常数和函数同理。**

**长度**：m, km, cm, mm, \*µm, nm, \*mile, \*ft, \*ly

**面积**：m², cm², \*mm²

**体积**：m³, cm³, \*mm³, L, mL

**(角)速度/加速度**：m/s, km/h, m/s², rad/s, \*rad/s²

**角度**：rad, °

**时间**：s, ms, min, h, \*d

**频率/转速**：Hz, \*r, r/min, \*r/s

**质量**：kg, t, g, \*mg, \*u

**密度**：g/cm³, kg/m³

**力与压强**：N, Pa, kPa, \*atm, mmHg

**能量与功率**：J, \*cal, \*eV, kWh, W, kW

**热学**：K, ℃, \*℉, Δ℃, \*Δ℉, J/(kg·K), J/(kg·℃)

**电磁学**：A, mA, V, mV, Ω, C, Ah, mAh, \*F, \*H, \*T, \*Wb

**物质的量**：mol, mol/L, g/mol, \*kg/mol

**光学**：\*cd

- **注：℃、℉是偏移单位，作温差时请使用Δ℃、Δ℉**

你也可以自由组合新的复合单位，如`N·m`。


## 物理常数

在表达式中可以直接使用常见物理常数，和一些常见数学常数（如`π`, `e`（自然常数）等）。

| 常数     | 符号  | 说明                  |
|--------|-----|---------------------|
| `π`    | π   | 圆周率                 |
| `e`    | e   | 自然常数                |
| `_g`   | g   | 重力加速度（9.80665 m/s²） |
| `_c`   | c   | 光速                  |
| `_G`   | G   | 万有引力常数              |
| `_k_e` | ke  | 库仑常量                |
| `_e_charge` | e   | 元电荷                 |
| `_N_A` | N_A | 阿伏伽德罗常数             |
| `_V_m` | Vₘ  | 气体摩尔体积(标况)          |
| `*_R`  | R   | 理想气体常数              |
| `*_h`  | h   | 普朗克常数               |
| `*_m_e` | mₑ  | 电子质量                |
| `*_m_p` | mₚ  | 质子质量                |
| `*_m_n` | mₙ  | 中子质量                |
| `*_epsilon_0` | ε₀  | 真空介电常数              |
| `*_mu_0` | μ₀  | 真空磁导率               |
| `*_k_B` | k   | 玻尔兹曼常数              |
| `*_F`  | F   | 法拉第常数               |

- **注：所有物理常数均以下划线开头（如_g），数学常数直接使用（如π、e）**
- **注：软件使用高精度常数，如_g=9.80665m/s²。**
- **注：带\*为不常用常数，默认不显示，但仍可正常使用，可在设置中启用。**


## 函数

| 函数             | 说明              |
|----------------|-----------------|
| `sin(x)`       | 正弦              |
| `cos(x)`       | 余弦              |
| `tan(x)`       | 正切              |
| `*cot(x)`      | 余切（1/tan）       |
| `*sec(x)`      | 正割（1/cos）       |
| `*csc(x)`      | 余割（1/sin）       |
| `asin(x)`      | 反正弦             |
| `acos(x)`      | 反余弦             |
| `atan(x)`      | 反正切             |
| `sqrt(x)`      | 平方根             |
| `abs(x)`       | 绝对值             |
| `log(x, base)` | 以 base 为底 x 的对数 |
| `lg(x)`        | 常用对数（以10为底）     |
| `ln(x)`        | 自然对数（以e为底）      |
| `mod(a,b)`     | a 对 b 取余        |

- **注：三角函数输入带`°`时按角度计算，输入纯数或`rad`时按弧度计算。反三角函数默认返回弧度。**
- **注：带\*为不常用函数，默认不显示，但仍可正常使用，可在设置中启用。**


## 特殊功能

- **ans**：引用上一次计算的结果。例如先算 `10m`，再输入 `ans×2` 得到 `20m`。
- **单位转换**：先点击“单位转换”按钮进入转换模式，再点击目标单位按钮，即可将当前结果转换到该单位。
- **错误提示**（尚不完善）：当表达式有误时，下方信息区会显示具体原因和建议修改方式。
